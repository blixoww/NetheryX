# Textures faites main

Toute image placée ici remplace la texture générée du même nom au moment de la génération des ressources
(`python3 tools/generate_resources.py`). L'arborescence suit celle des ressources du mod :

```
art/assets/netheryx/textures/item/onyx_helmet.png
art/assets/netheryx/textures/models/armor/onyx_layer_1.png
...
```

Pour remplacer une texture : dessinez-la (Aseprite, Paint.NET, Blockbench…), enregistrez-la ici sous le même nom,
puis copiez-la aussi dans `src/main/resources/assets/netheryx/...` (ou lancez le générateur).
